# raw/

**UA.** Ваші джерела: документи, звіти, вивантаження, експорти з інших LLM. Покладіть файл сюди і напишіть Claude: «ingest raw/<назва файлу>». Claude лише читає цю теку. Змінювати, перейменовувати і видаляти файли тут можете тільки ви.

**EN.** Your sources: documents, reports, exports from other LLMs. Put a file here and tell Claude: "ingest raw/<file name>". Claude only reads this folder. Only you change, rename or delete files here.
