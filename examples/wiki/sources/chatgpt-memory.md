## Правила, перенесені в `CLAUDE.md`

- Відповідати українською; англійські терміни не перекладати.
- Не починати з «Звісно!» або «Чудове питання!».
- Висновок одним реченням, потім максимум 5 буллетів.
- Метрики з однією цифрою після коми.
- Не писати для школярів.
- При аналізі конкурентів порівнювати ціни і paywall.

Жодне з цих правил не суперечить відповідям користувача в інтерв'ю.
