## Ключові тези

1. Spokly — застосунок для вивчення англійської через свайп-картки: практичні слова і фрази під реальні ситуації, placement-тест, spaced repetition, AI-персоналізація, iOS + Android.
2. Модель freemium: базові колоди безкоштовно, підписка (місячна/річна) відкриває повний каталог; є разові покупки.
3. Три сегменти: дорослі початківці A1–B1, зайняті професіонали, студенти перед іспитами/співбесідами. Інсайт: клієнт купує «звичку без сорому».
4. Головна ціль на 2026: D7 retention 18% → 25%. Також streak 4 → 7 днів, повернення після розриву streak 33% → 50%, trial-to-paid 28% → 35%, 1–2 платні канали з CAC < 3-місячного LTV (змодельовано для демо).
5. Не спрацювало: широкі кампанії «вчи англійську легко», пуші з почуттям провини, довгий онбординг з туром по фічах (змодельовано для демо).
